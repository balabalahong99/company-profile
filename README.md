# 公司速览 · Company Profile

一个用于企业公开资料查询的 Codex 技能。输入公司名称、简称、外文名或品牌名，先确认对应的企业主体，再生成带来源和日期的中文速览。适合做行业调研、了解客户或供应商，以及快速查找财报与在华经营信息。

## 能查到什么

| 内容 | 输出 |
| --- | --- |
| 公司身份与所属国家 | 常用名、法定名称、注册国家或地区、身份依据。总部与注册地不同时分别列出。 |
| 主营与次要业务 | 各业务提供的产品或服务、面向的客户，以及划分主次的依据。 |
| 历年总营业额 | 按财年列出可核实的营业收入，注明财年截止日、币种、单位、来源和数据缺口。 |
| 旗下产品与品牌 | 代表性产品或品牌的用途，以及自有、授权经营或合资等关系。 |
| 中国区员工 | 可核实的人数、统计日期、地域和覆盖实体。默认优先查询中国大陆。 |
| 在华投资 | 可核实的累计金额与代表性项目，注明投资主体、地点、金额、进展和来源。 |

## 快速开始

1. 打开本仓库的 [SKILL.md](SKILL.md)，下载原始文件。
2. 将文件保存到个人目录下的 `.agents/skills/company-profile/SKILL.md`，供各项目使用。也可以将它放到某个项目根目录下的同一路径，仅在该项目中使用。
3. 在 Codex 中输入公司名称，或用 `$company-profile` 显式调用。技能未出现在选择列表时，可以重启 Codex 后再试。

个人目录在 Windows 上通常是 `%USERPROFILE%`，在 macOS 和 Linux 上通常是 `~`。技能依赖当前会话能检索公开资料。 [Codex 技能官方文档](https://learn.chatgpt.com/docs/build-skills)

### 调用示例

| 输入 | 适用场景 |
| --- | --- |
| `$company-profile 比亚迪` | 获取完整的公司速览。 |
| `$company-profile 西门子，营收只查 2021–2025 财年` | 限定营收查询区间。 |
| `$company-profile 长城，指长城汽车（601633）` | 用证券代码消除简称歧义。 |
| `$company-profile 施耐德电气，重点查中国大陆员工和已落地的投资` | 聚焦在华经营，并区分计划与实际进展。 |

## 怎样定位公司、核对数字

- **同名或简称有歧义**时，先列候选公司的法定名称、所在国家或地区、业务和匹配依据，再请你确认。公司主体可唯一定位时，直接给出速览。
- **营收优先采用合并报表数据**。以公司披露的完整财年为准，保留原币种，标注重述值和合并范围变化。
- **在华信息按来源原口径呈现**。例如大中华区人数、单一子公司人数会注明覆盖范围。投资项目会区分计划、签约和实际到资，也会注明金额是项目总额、企业出资还是注册资本。
- **资料缺失或冲突时**，标记未查到或未能确认，并说明查阅资料的时间范围。关键数字优先链接到年报、监管披露、公司公告或政府项目公告。
